# Fashion Data Quiz

Quiz breaks for the Fashion Data Science course (Week 1).

Live site: https://ilaydabegumizci.github.io/fashion-data-quiz/

- **Present to the class**: the lecturer shows one question at a time on the projector and reveals the answer.
- **Play on my phone**: each student answers privately; wrong answers name the slide to revisit.
- **Play as teams**: optional team game with a scoreboard.
